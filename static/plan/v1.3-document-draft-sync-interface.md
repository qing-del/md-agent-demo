# 文档草稿同步接口 v1.3

## 保存文档草稿

```http
PUT /api/documents/{documentId}
Content-Type: application/json
```

请求：

```json
{
  "content": "# Java\n\nJDK 应从 Oracle 官网下载"
}
```

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `documentId` | number | 是 | 路径中的文档 ID |
| `content` | String | 是 | 前端当前完整 Markdown 草稿；不传 Operation、`opId` 或 `sectionText` |

成功响应：`200 OK`

```json
{
  "documentId": 1,
  "status": "SYNCED",
  "updatedAt": "2026-09-09T12:00:00"
}
```

前端收到成功响应后，将文档状态更新为“已同步”。请求失败时沿用 v1.0 错误响应，前端提示错误信息并保持“未同步”；保存成功前，后续 AI 请求仍读取数据库中的旧文本。
