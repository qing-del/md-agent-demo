# Markdown AST Tool 设计

## 目标

将一段 Markdown 文本解析为可按 UUID 管理的标题树，并支持查询目录和指定标题节点的内容预览。

## 数据结构

每个 UUID 对应一份不可变的 Markdown 上下文：

```java
MarkdownContext
├── UUID key
├── List<HeadingNode> headingTree
├── Map<Integer, String> contentByNode
└── String documentPreamble
```

标题节点保存：

```java
HeadingNode
├── int number
├── int level
├── String rawHeading
├── String title
└── List<HeadingNode> children
```

- `number` 按标题在原文中的出现顺序从 1 开始，在当前 Markdown 快照内唯一。
- `rawHeading` 保留完整标题形式，如 `## 安装`。
- `contentByNode` 只保存对应标题下面、下一个标题之前的直接正文。
- 标题前的正文保存在 `documentPreamble` 中。
- 上下文通过 `Map<UUID, MarkdownContext>` 管理；重新解析相同 UUID 时整体替换旧快照。

## 解析规则

解析标题时使用栈按照标题等级建立父子关系：

```text
1. # Java
2. ## 安装
3. ### JDK 安装
4. ## 开发工具
5. # Python
6. ## 安装
```

对应结构：

```text
根节点
├── 1. # Java
│   ├── 2. ## 安装
│   │   └── 3. ### JDK 安装
│   └── 4. ## 开发工具
└── 5. # Python
    └── 6. ## 安装
```

## 节点内容预览

查询指定节点时返回：

1. 当前节点的标题。
2. 当前节点的直接正文。
3. 当前节点的直属子标题，不递归展开孙级节点。
4. 子标题存在直接正文或子节点时，在标题后追加 `...`。

例如查询 `# Java` 节点：

```markdown
# Java
Java 是世界上最伟大的语言
接下来我们讲解如何安装 Java

## 安装 ...
## 开发工具 ...
## 技术栈
```

省略号表示该子标题下仍有可继续查询的内容或结构，不存入正文 Map，由查询时动态生成。

## 接口定义

```java
MarkdownContext getEntity(UUID key);

String getHeadingTree(UUID key);

String getSectionPreview(UUID key, int nodeNumber);

String getSectionAll(UUID key, int nodeNumber);
```

- `getEntity`：获取 UUID 对应的完整 Markdown 上下文实体。
- `getHeadingTree`：获取带节点编号的标题目录树。
- `getSectionPreview`：获取指定编号节点的正文及折叠后的直属子标题。
- `getSectionAll`：获取指定编号节点的标题、直接正文和全部后代节点内容，并保持原文顺序与 Markdown 格式。

`getSectionAll` 的返回内容最大为 5 KB（5120 个 UTF-8 字节）。超过限制时，在 UTF-8 字符边界处截断，并在末尾追加 `...`；追加省略标记后的总大小不得超过 5 KB。
